# Workflow

Use `main`, `develop` e features baseadas no `develop` atualizado; documente branches empilhadas. Antes de agir, confirme branch, commits e pré-requisitos. Um slice por tarefa. Dependências, migrations, providers, custos e APIs públicas passam por revisão explícita. Codex valida, deixa mudanças sem commit e apenas sugere commit; não faz push ou Git destrutivo sem autorização.

# Estratégia de IA

IA é consultiva e posterior a regras. Gemini Developer API gratuita é a direção aprovada; OpenAI atual é transitório e não validado ao vivo, sem fallback pago ou crédito de ChatGPT Plus. Análise automática futura atende somente resultados de maior prioridade dentro da quota. Análise manual poderá ser solicitada para qualquer vaga persistida, inclusive rejeitada, sem alterar a regra. Quota esgotada marca/enfileira análise e não para coleta, persistência ou filtro. Resultados nunca garantem contratação, inventam fatos ou enviam candidaturas.
